# Open problems

A problem appears here when a literature check found no published solution. Each entry states what
has been tried, what the best published result achieves, and where it falls short. "Nobody knows" is
a finished answer and is worth more than a confident wrong selection.

An entry must state the check that produced it: which searches were run, which bibliographies were
mined forward, and what the most recent relevant publication is. A problem recorded as open without
that check is a guess.
