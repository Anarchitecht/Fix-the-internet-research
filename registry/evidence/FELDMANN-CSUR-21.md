## [FELDMANN-CSUR-21] Survey on Algorithms for Self-Stabilizing Overlay Networks
**Citation:** Michael Feldmann, Christian Scheideler, Stefan Schmid. "Survey on Algorithms for Self-Stabilizing Overlay Networks." ACM Computing Surveys, 2021 (publication date given on the document itself as January 2020). DOI 10.1145/3397190.
**Retrieved:** full text via https://schmiste.github.io/csur20.pdf
**Source URL:** https://schmiste.github.io/csur20.pdf
**Domain:** A

### What it does
This survey classifies distributed algorithms that let an overlay network (a graph of logical links among peers, each link a path through the underlying physical network) recover a specified target topology starting from any initial graph, including one corrupted by faults, without central coordination. A protocol satisfying this is called self-stabilizing, defined by two properties the survey states explicitly: convergence (from any system state, the protocol reaches a legitimate state matching the target topology) and closure (once in a legitimate state, the protocol stays there). The survey runs no experiments of its own; every quantitative result below is a runtime or work bound the survey states as proved in the paper it discusses, not a measurement the survey authors performed.

The survey identifies four local graph operations — Introduce, Forward, Merge, Invert — as the building blocks every self-stabilizing overlay protocol in its taxonomy composes: Introduce sends a node's own reference to one of its two known neighbors, connecting them; Forward relays a held reference to another neighbor and drops the local copy; Merge collapses two references to the same node into one; Invert reverses the direction of a link from explicit (a stored reference) to implicit (a reference in transit). The survey states a proof that Introduce, Forward, and Merge alone suffice to convert any weakly connected graph into any strongly connected target graph, and that adding Invert makes the four sufficient to reach any weakly connected target graph, and further states these four are also individually necessary, since each performs an operation none of the other three can (Introduce is the only edge-creating operation, Forward the only node-separating operation, Merge the only edge-removing operation, Invert the only operation that can render a node unreachable from another).

The survey classifies self-stabilizing overlay designs by target topology: linearization (sorted lists and the de Bruijn graph), metrical graphs (line and circular metrics, general and special metrics under local or global probing, Euclidean metrics), and expanders (skip graphs, random graphs, and a general Transitive Closure Framework that derives a self-stabilizing protocol for any locally checkable target topology). For skip graphs specifically, the survey describes SKIP+ as the first self-stabilizing scalable design in this line: SKIP+ distinguishes stable edges (already part of the skip graph structure from a node's local view) from temporary edges (forwarded toward a neighbor for which they would be more relevant), and every node continuously runs three rules — create reverse edges, forward temporary edges, and locally close and sort neighbors by identifier. The survey states SKIP+'s own paper proves convergence from any weakly connected graph to a skip graph in O(log^2 n) rounds, and that a single join or leave event requires polylogarithmic work. The survey states HSKIP+ (Feldotto, Scheideler, Graffi, 2014) is "an improved version" of SKIP+ that "reduces the stabilization time in practice and needs less work for single join or leave events," without stating a numeric bound for either improvement.

### Measured results
This survey states no measurement of its own; every bound below is a theorem the survey reports as proved in the cited primary paper.

| Result stated by the survey | Source |
|---|---|
| SKIP+ converges from any weakly connected graph to a skip graph in O(log^2 n) rounds; a single join or leave event requires polylogarithmic work | Jacob, Richa, Scheideler, Schmid, Täubig (cited as [25], the SKIP+ paper) |
| The Transitive Closure Framework converges to any locally checkable target topology in at most D(n) + log n + 1 rounds, where D(n) is the maximum distance from any non-detector node to its nearest detector node | Cited as [9] |
| The Transitive Closure Framework yields an O(log n)-time self-stabilizing algorithm for the SKIP+ topology specifically, which the survey states is optimal because any self-stabilizing algorithm requires time at least the diameter of the network in its legitimate state | Same source, applied to SKIP+ |
| A generalized edge-flip rule ("k-Flipper") transforms any d-regular connected graph into a connected d-regular Θ(d)-expander using O(dn) applications of a Θ(d^2 n^2 log(1/ε))-Flipper operation, for d ∈ Ω(log n) | Cited as [39] |
| The Finite Departure Problem (a node leaving the system permanently, entering an "exit" state) cannot be solved by any self-stabilizing protocol using only local control — an oracle is required | Cited as [Theorem 7.2, referencing [18]] |
| The Finite Sleep Problem (a node leaving temporarily, entering a "sleep" state reachable again by a later message) can be solved by local control protocols alone | Same source, [18] |

### Parameters
This survey states no parameters of its own; the bounds above are stated in terms of n (node count), d (target graph degree), and D(n) (a topology-specific detector-distance function), each defined by its cited source.

### Stated limitations
The survey states, in its own concluding section, four open problems it identifies as unresolved across the entire self-stabilizing-overlay literature it surveys, not limited to any one paper: (1) upper and lower bounds on the total work (edges inserted, changed, or removed during convergence) are known for very few topologies, in contrast to the more developed literature on convergence time; (2) transient behavior during convergence is not well understood — the survey states a node's degree "may temporarily raise significantly, far beyond the maximum initial or final node degree" even for topologies that are degree-bounded once stable, and designing algorithms that also bound degree during convergence is stated as an open question; (3) no general theory connects the convergence time or work of a self-stabilizing protocol to "how far" the initial topology is from the target, a property the survey calls locality; (4) the survey states explicitly, in its own words, that research on churn-tolerant overlays and research on self-stabilizing overlays "has been largely independent" of each other, so no general result in this survey's own scope bounds how much concurrent join/leave activity a self-stabilizing protocol can tolerate while still converging. Separately, the survey states that monotonic searchability (a guarantee that once a search for a target node succeeds, every later search for the same target also succeeds) is not satisfied by the straightforward routing algorithm for a self-stabilizing sorted list, and that the general protocol achieving monotonic searchability across a wide range of target topologies can force a search for a non-existent node to traverse up to Ω(n) hops before terminating.

This survey's own bibliography and text contain no mention of bandwidth or node-capacity heterogeneity anywhere except in the title of the single reference it cites for HSKIP+ itself. No self-stabilizing overlay design published in the window this survey covers is presented by the survey as improving on, or even revisiting, HSKIP+'s specific property of ordering routing by node bandwidth. This is a negative finding, not a claim that no such design exists elsewhere in the literature — it states only that this survey, read in full, does not surface one.

### Requirements it places on the rest of the system
The model underlying every protocol in this survey assumes a static node set: the survey states node departures are only addressed as a separate, later-developed extension (Section 7.2), and that termination of the self-stabilization process may not be reached if the node set changes during convergence, citing a proof of this in the surveyed literature. Every protocol in this survey's basic model assumes fair message receipt (every message sent is eventually processed) and weakly fair action execution (an action enabled in all but finitely many states is executed infinitely often), with no bound placed on message propagation delay or relative node execution speed — the model is explicitly asynchronous. Every protocol assumes node identifiers are correct and uncorrupted in the initial state and are manipulated only by comparison, storage, and transmission (never recomputed or reassigned) — a self-stabilizing overlay protocol in this survey's model cannot repair a corrupted node identifier itself and requires an external mechanism (a failure detector or an identifier-assignment scheme) to guarantee identifier correctness before the protocol begins. A protocol solving the Finite Departure Problem specifically requires an oracle, per Theorem 7.2 — no purely local protocol can guarantee that a permanently departing node's references are fully purged from the system, so any system requiring that guarantee must supply an oracle mechanism the survey's local-primitive protocols do not provide on their own.

### Contradicts
None found within this corpus. This entry supplies a negative finding relevant to the brief's HSkip+ evaluation: this survey, forward-mined specifically to check for a post-2014 design dominating HSkip+ on bandwidth-heterogeneous routing, does not identify one.
