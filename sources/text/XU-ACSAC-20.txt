Threat Model
Linear Loopy Belief Propagation (LinLBP) is a collective classification method. The LinLBP 
system is defined by training dataset and edge weight. 
• Training dataset of LinLBP is a small subset of labeled positive nodes and negative nodes with 
known prior reputation scores, serving as a prior knowledge of LinLBP system to start belief 
propagation.
• Edge weight is the other parameter that affects the LinLBP classification result. Weight of each 
edge in LinLBP system is identical. 
Attacker’s knowledge can be classified based on these two factors.
• Full/partial knowledge of training dataset
• Know/not know the exact weight value

Conclusion
• Proposed a new attack on collective classification methods for graphs by adding 
fake nodes into original graphs without modifying existing connections.
• Formulated the new attack as an optimization problem to generate edges of new 
added fake nodes.
• Extensive experiments on real-world social network data show our attack can 
achieve high FNRs on both new fake nodes and target nodes, even if an attacker 
does not have full knowledge of the node classification system.
